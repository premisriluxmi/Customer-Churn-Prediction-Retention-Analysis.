# Customer Churn Prediction & Retention Analysis

## Project Overview
Customer Churn Prediction & Retention Analysis is a machine learning project that aims to understand customer behaviour and identify customers who may leave a service.

The project uses customer data to explore churn patterns and eventually develop machine learning models that can help businesses improve customer retention.

## Day 1 – Data Understanding and Initial Analysis

### Tasks Completed
- Loaded the customer churn dataset using Pandas.
- Explored the dataset structure, rows, columns, and data types.
- Generated statistical summaries.
- Checked missing values and duplicate records.
- Analyzed customer churn distribution and percentages.
- Explored customer gender, contract types, and payment methods.
- Created visualizations to understand churn patterns, monthly charges, and customer tenure.
- Saved the dataset for further analysis.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset
The project uses a Telco Customer Churn dataset containing customer information, subscription details, services, charges, and churn status.
